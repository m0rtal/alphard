ENVIRONMENT CONSTRAINT (2026-08-24):
  LXC sandbox blocks AppArmor docker-default profile load for ANY new container:
    "running /usr/sbin/apparmor_parser -Kr /var/lib/docker/tmp/docker-defaultXXX
     failed with output: apparmor_parser: Unable to replace "docker-default".
     apparmor_parser: Access denied. You need policy admin privileges..."
  Verified reproduction with a minimal /tmp/verify-prom-hc.yml (single
  prom/prometheus service) — Container Created → Start fails with the same
  apparmor error. This is a host-level LXC limitation that pre-exists
  this PR; it cannot be remediated from inside a non-privileged user
  container.
