# Alphard production crontab (Phase 1.6 audit).
#
# Schedule rationale (MSK = UTC+3; MSK 19:00 → server local
# 16:00 UTC since the container runs UTC):
#
#   ms=minute hour day month dow command
#
# daily_sync   — every weekday at MSK 19:00 (16:00 UTC) pull last 5
#                trading days for the top-20 MOEX liquid universe via
#                Tinkoff gRPC. Idempotent: UPSERT ON CONFLICT DO NOTHING
#                per (ticker, ts, source) PK.
#
# freshness    — every 5 minutes — emit non-zero exit code if the
#                last ohlcv_daily row is > 24h old, so cron monitor
#                (Prometheus/blackbox-exporter) fires.
#
# db_health    — every minute — auth_probe() on the postgres role.
#                Non-zero on auth drift (H-9 defense-in-depth).
#
# m=0  h=19  *  * 1-5 python /app/scripts/daily_sync.py             --days=5     --dsn=$ALPHARD_PG_DSN >> /app/logs/cron.log 2>&1
*/5  *  * * * * python /app/scripts/check_data_freshness.py                                         >> /app/logs/cron.log 2>&1
